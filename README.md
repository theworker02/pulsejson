# pulsejson

Pulse digests and json fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/pulsejson/

## Install / run

```bash
git clone https://github.com/theworker02/pulsejson.git
cd pulsejson
node src/cli.js
node --test
```
